# 🚀 Proyecto Final 15 | Data Analytics — TripleTen

## 👩‍💻 Descripción del proyecto

Este repositorio contiene el desarrollo de mi **Proyecto Final de Análisis de Datos**, en el que integré los conocimientos adquiridos durante el bootcamp de TripleTen mediante tres casos prácticos relacionados con bases de datos, análisis de telecomunicaciones y experimentación A/B.

El objetivo es aplicar herramientas de análisis de datos para explorar información, identificar patrones, evaluar resultados y formular conclusiones que contribuyan a la toma de decisiones.

## 📚 Caso 1. Análisis de una base de datos de libros con SQL

### 🎯 Objetivo
Analizar una base de datos relacionada con libros, autores, editoriales, calificaciones y reseñas para obtener información útil sobre el catálogo y la actividad de los usuarios.

### 🔎 Actividades realizadas
- Exploración de las tablas y sus estructuras.
- Consulta de información mediante SQL.
- Análisis de libros, autores y editoriales.
- Evaluación de calificaciones y reseñas de los usuarios.
- Elaboración de conclusiones a partir de los resultados obtenidos.

### 🛠️ Herramientas
- SQL
- PostgreSQL
- Python
- Jupyter Notebook

---

## 📞 Caso 2. Análisis de operadores de telecomunicaciones

### 🎯 Objetivo
Analizar el comportamiento de las llamadas y los clientes para identificar operadores ineficaces mediante indicadores de desempeño y pruebas estadísticas.

### 🔎 Actividades realizadas
- Exploración y preparación de los conjuntos de datos.
- Limpieza y validación de la información.
- Análisis del comportamiento de las llamadas.
- Cálculo de indicadores de desempeño de los operadores.
- Análisis exploratorio mediante tablas y visualizaciones.
- Aplicación de pruebas estadísticas para evaluar diferencias.
- Elaboración de conclusiones y recomendaciones.

### 🛠️ Herramientas
- Python
- Pandas
- NumPy
- Matplotlib
- SciPy
- Jupyter Notebook

---

## 🧪 Caso 3. Evaluación de un sistema de recomendaciones mediante una prueba A/B

### 🎯 Objetivo
Evaluar si un sistema de recomendaciones mejorado incrementa la conversión de los usuarios durante los primeros 14 días posteriores a su registro.

### 🔎 Actividades realizadas
- Exploración y preparación de los conjuntos de datos.
- Revisión de usuarios participantes en los grupos de prueba.
- Identificación y tratamiento de usuarios que participaron simultáneamente en experimentos.
- Filtrado de usuarios y eventos conforme a los criterios del experimento.
- Análisis del embudo de conversión: página del producto, carrito y compra.
- Comparación de las tasas de conversión entre los grupos.
- Aplicación de pruebas estadísticas y corrección de Bonferroni.
- Interpretación de resultados y elaboración de conclusiones.

### 🛠️ Herramientas
- Python
- Pandas
- NumPy
- SciPy
- Matplotlib
- Jupyter Notebook
